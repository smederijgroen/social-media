# Blender: Vistamont vide

Open vistamont_vide.py in Blender (Scripting > Open > Run Script). Texturen en HDRI in tex/ zijn CC0 van Poly Haven.
Bovenaan het script: ENGINE (EEVEE of CYCLES), PROFIEL (zijkant of vloer), PROFIEL_KLEUR, maten van de vide.
Renderen: Render > Render Animation, of blender -b -P vistamont_vide.py -- --render
